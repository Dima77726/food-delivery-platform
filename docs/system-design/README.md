# System design на примере проекта

Учебник: каждая глава разбирает тему system design на коде этой платформы. В каждой главе есть
схема, компромиссы («почему так, а не иначе») и ссылки на конкретные классы в репозиториях сервисов.
Пути вида `order-service/src/...` указывают внутрь репозитория соответствующего сервиса.

| № | Глава | Что внутри |
|---|---|---|
| 1 | [Доставка в реальном времени](01-realtime-delivery.md) | polling, long polling, SSE, WebSocket, вебхуки; fan-out между экземплярами; «сигнал + чтение»; thundering herd; таймауты прокси и пульс |
| 2 | [Идемпотентность и ограничение частоты](02-idempotency-and-rate-limiting.md) | ключи идемпотентности (оплата, чат), лёгкие транзакции Cassandra, token bucket в памяти и в Redis |
| 3 | [Вебхуки и ключи API](03-webhooks-and-api-keys.md) | исходящие вебхуки (Standard Webhooks, лестница повторов, аренда, SSRF, автовыключение), входящие Stripe и Telegram, ключи API и обмен на токен, безопасная выкатка |
| 4 | [Интеграции](04-integrations.md) | MQTT и HTTP-бэкенд аутентификации брокера, Web Push (RFC 8291, VAPID), gRPC server streaming и обратное давление, Spring Batch, CDC (Debezium → Kafka → ClickHouse) против outbox, AsyncAPI, как выбирать транспорт |
| 5 | [Бизнес-функции](05-business-features.md) | Redis GEO и geohash, автоназначение курьера через предложения, отложенные задачи, ShedLock и пределы распределённых блокировок, атомарный счётчик промокода, фильтр Блума в Redis, динамическая цена (EMA), частичные возвраты |
| 6 | [ИИ-агент](06-ai-agent.md) | цикл модели и инструментов, права через роль и токен пользователя, действия с подтверждением человека и prompt injection, RAG (BM25, стеммер, гибрид через RRF), поток SSE через fetch, проактивные сообщения из Kafka, MCP |

Все пять фаз плана закрыты; новые главы появятся вместе с новыми темами.

Темы, которые в проекте уже есть и описаны в [README платформы](../../README.md): outbox и inbox,
сага оплаты, database-per-service, CQRS-проекции в пять хранилищ, circuit breaker, трассировка.
